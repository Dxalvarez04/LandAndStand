Files served to the browser. They are used by the map and the computation (Web Worker).

| File | What it is | How to get it | Status |
|---|---|---|---|
| `dem_real.bin` | DEM 110 × 110 float32 LE, 32 m cells, **row 0 = south** (read by the computation and the map relief) | `python3 scripts/preparar_datos.py` (from the official USGS DEM) | ✓ |
| `dem_real.json` | Shape, order, source and elevation range of the DEM | Written by the same script | ✓ |
| `aoi_color.jpg` | Color HiRISE background, 1320 × 1320, **north up** | `python3 scripts/preparar_datos.py` (from the official USGS color mosaic) | ✓ |
| `contexto_color.jpg` | HiRISE terrain around the area (1 km to the west, 3 km to the north, east and south), 5 m/px. Visual only: context in the 2D map and image of the local terrain in 3D | `python3 scripts/preparar_datos.py`; the `entorno` step of `preparar_datos_3d.py` remakes it with the strips the mosaic only has in grayscale colorized | ✓ |
| `relieve.png` | Shaded relief of the area at 8 m, gray 128 = flat (drawn on top of the probability) | `python3 scripts/preparar_datos.py` | ✓ |
| `draws_seed11_300.json` | Reference draws from the technical report, for its validation protocol | Not included. If present, the computation uses it; if not, it generates 300 draws with seed 11 | Optional |
| `real_prob_con.bin` | Reference map from the technical report (visual validation) | Not included. Convert it with `python3 scripts/npy_a_bin.py results/real_prob_con.npy public/data/real_prob_con.bin` | Optional |

**DEM validation** against the technical report (section 4):
- Elevation range of the area: 547 m (the report says 546 m).
- Rock Hall: 1.22 km from the habitat and +156 m (the report says 1.2 km and +157 m).
- Edinburgh: 1.72 km and +210 m; Mary Anning: 1.79 km and +170 m (the report says 1.7–1.8 km and +170–210 m).

The technical report's `dem_real.npy` can be used instead: `python3 scripts/npy_a_bin.py data/dem_real.npy public/data/dem_real.bin`.

## Manual crop with GDAL (equivalent to the script)

The window of the official **HiRISE color mosaic** (see `docs/data-sources.md`) can be cropped with GDAL. It is a COG, so GDAL reads only the part it needs over HTTP, without downloading the 1 GB file.
The window is in the same projection as the mosaic (Mars equirectangular, central meridian 0, R = 3,396,190 m; checked in the file header):

```bash
gdal_translate -projwin 8141000 -278480 8144520 -282000 -outsize 1320 1320 -r average \
  /vsicurl/https://asc-pds-services.s3.us-west-2.amazonaws.com/mosaic/Mars/MSL/MSL_Gale_HiRISE-LRGB_78quads_sharp_cog.tif \
  aoi_color.tif
gdal_translate -of JPEG -co QUALITY=88 aoi_color.tif aoi_color.jpg
```

`-projwin` takes the order ulx uly lrx lry (upper left and lower right), so the image comes out with north up.
Visual check: points T1–T6 on the map should fall on Curiosity's sampling sites.
